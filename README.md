# Task 2 – Number Pattern Generator 🔢

This Java program prints numeric patterns based on user input. It's a simple console application focused on nested loops and user interaction.

## 📌 Features
- Input-driven pattern
- Loop-based row generation
- Customizable by user input

## 🛠️ Technologies Used
- Java
- Maven
- IntelliJ IDEA

## 🚀 How to Run
1. Clone the repo or download the files
2. Open the project in IntelliJ
3. Run `PatternPrinter.java` from the `com.cognifyz` package
